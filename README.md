# رهگذر (Rahgozar) | نرم‌افزار هوشمند و تطبیقی دسترسی آزاد به اینترنت
**نسخه ۱.۰.۰ پایدار برای ویندوز ۱۰ و ۱۱ نسخه ۶۴ بیتی (Windows 10/11 x64)**

---

## ۱. معرفی و فلسفه پروژه
**رهگذر (Rahgozar)** یک نرم‌افزار دسکتاپ مدرن، امن و چندلایه است که به طور اختصاصی جهت تشخیص نوع و شدت اختلالات اینترنت در شبکه‌های اپراتورهای ایران (همراه اول، ایرانسل، رایتل، شاتل، مخابرات و ...) و برقراری ارتباط پایدار، رمزنگاری‌شده و بهینه با اینترنت آزاد بین‌الملل توسعه یافته است.

رهگذر بر خلاف نرم‌افزارهای سنتی یا نمونه‌های نمایشی، اتصالات را جعل نمی‌کند و به عنوان یک دستیار مهندسی واقعی، تک‌تک مراحل سنجش و اتصال را به صورت زنده و شفاف به کاربر نشان می‌دهد.

---

## ۲. ویژگی‌های کلیدی مهندسی

### ۲.۱. موتور تشخیص تطبیقی فیلترینگ (ANDE - Adaptive Network Diagnosis Engine)
سنجش مستقل و تفکیک‌شده لایه‌های مختلف شبکه در ۶ سطح شدت (از ۰ تا ۵):
* **بررسی پیوند محلی:** تشخیص اتصال فیزیکی یا Wi-Fi و دریافت IP معتبر از روتر.
* **آزمون جعل DNS:** مقایسه پاسخ DNS اپراتور با سرورهای عمومی (8.8.8.8) و پروتکل DoH رمزگذاری‌شده جهت شناسایی IPهای جعلی (مانند 10.10.34.34 یا 10.10.34.35).
* **آزمون اتصال TCP و تزریق بسته RST:** اندازه‌گیری زمان اتصال به مقاصد کنترلی داخلی و بین‌المللی و شناسایی بسته‌های TCP RST ارسالی توسط فایروال DPI.
* **آزمون فیلترینگ هوشمند TLS و بازرسی SNI:** آزمون دست‌دهی با دامنه‌های فیلترشده در برابر دامنه‌های بدون اختلال جهت تشخیص دقیق مسدودسازی در بسته ClientHello.
* **آزمون افت پکت و محدودسازی UDP:** اندازه‌گیری دقیق درصد بسته‌های گم‌شده روی پروتکل‌های UDP جهت سنجش کارایی WireGuard و QUIC.
* **تشخیص وضعیت اینترنت ملی (Intranet):** شناسایی شرایطی که ترافیک داخلی برقرار است اما کلیه خروجی‌های بین‌المللی مرزی قطع شده‌اند.

### ۲.۲. موتور انتخاب تطبیقی مسیر (ATS - Adaptive Transport Selector)
* حذف خودکار پروتکل‌های ناسازگار با وضعیت لحظه‌ای شبکه (مثلاً عدم انتخاب پروتکل UDP در شرایط افت بالای ۸۰٪ بسته‌ها).
* راستی‌آزمایی واقعی داده‌ها (Canary Verification) از طریق ارسال درخواست به اندپوئینت‌های بین‌المللی معتبر؛ هیچ اتصالی بدون انتقال موفق داده تایید نمی‌شود.
* پایش مداوم سلامت مسیر با پینگ‌های نامحسوس دوره‌ای.
* تعویض خودکار مسیر بدون لرزش (Anti-Flapping Auto-Failover) در صورت بروز ۳ خطای متوالی.

### ۲.۳. دو حالت اصلی اتصال
1. **بدون VPS شخصی (No-VPS Mode):**
   * بهره‌گیری از پل‌های ضدسانسور Tor شامل **Snowflake** (مبتنی بر WebRTC و دامنه‌های فرانت‌شده داخلی/خارجی) و **WebTunnel** (مخفی‌سازی ترافیک درون درخواست‌های عادی وب).
   * امکان ورود دستی پل‌های اختصاصی و تنظیم خودکار پراکسی سیستم.
2. **با VPS شخصی (Personal VPS Mode):**
   * پشتیبانی کامل از پروتکل‌های مدرن: **VLESS** (با XTLS-Reality و شبیه‌سازی فینگرپرینت uTLS کروم)، **Hysteria 2** (پروتکل قدرتمند UDP Brutal)، **Trojan**، **Shadowsocks**، **TUIC** و **VMess**.
   * واردسازی آسان از طریق کپی لینک یا QR Code.

### ۲.۴. امنیت و محافظت از اطلاعات حساس ویندوز
* **بازیابی ۱۰۰٪ ایمن تنظیمات رجیستری ویندوز:** قبل از فعال‌سازی پراکسی، نسخه پشتیبان از کلیدهای WinINet ذخیره شده و در زمان خروج عادی، خطای اضطراری یا کرش، تنظیمات ویندوز فوراً به حالت اول برگردانده می‌شود.
* **رمزنگاری مخزن محلی:** تمام پسوردها، UUIDها و کلیدهای خصوصی با استفاده از الگوریتم استاندارد **AES-256-GCM** و کلید وابسته به سخت‌افزار سیستم ذخیره می‌شوند.
* **پاکسازی لاگ‌ها (Log Sanitization):** هیچ شناسه یا اطلاعات حساسی در لاگ‌ها یا خروجی‌های تحلیلی افشا نمی‌شود.

### ۲.۵. رابط کاربری مدرن و دستیار زنده ۳ سطحی
* طراحی بر اساس متدهای پیشرفته بصری، معماری دوبل-بزل (Double-Bezel) و تایپوگرافی فارسی وزیرمتن (Vazirmatn).
* **دستیار زنده با ۳ سطح توضیح:**
  1. *کاربر مبتدی:* توضیحات ساده و بدون واژگان پیچیده فنی.
  2. *درک علت و جزئیات:* شرح سازوکار شبکه و دلیل فنی هر تصمیم.
  3. *گزارش تخصصی:* مشاهده لاگ خام سوکت‌ها، کدهای خطای شبکه و وضعیت بسته‌ها.

## ۳. راهنمای نصب و اجرا

### پیشنیازها
* ویندوز ۱۰ یا ۱۱ نسخه ۶۴ بیتی
* Node.js نسخه 20 یا بالاتر (برای اجرای سورس کد)

### اجرای سریع سورس کد در محیط توسعه:
```bash
# نصب وابستگی‌ها
npm install

# اجرای تست‌های خودکار
npm test

# اجرای برنامه در حالت توسعه (Live Dev)
npm run dev
```

### ساخت نسخه اجرایی نهایی (Windows Portable & Installer):
```bash
# کامپایل سورس و ایجاد دایرکتوری اجرایی ویندوز
npm run package
```
فایل اجرایی برنامه در مسیر زیر تولید می‌شود:
`release/win-unpacked/Rahgozar.exe`

│       │   └── log-sanitizer.ts    # پاکسازی توکن‌ها و IPها از لاگ‌ها

## ۵. گزارش آزمون‌ها و تضمین کیفیت
کلیه آزمون‌های برنامه با ابزار Vitest با موفقیت کامل (۱۰۰٪ سبز) اجرا شده‌اند:
* `tests/config-parser.test.ts`: اعتبارسنجی پارس VLESS Reality, VMess, Trojan, Hysteria 2, Tor و گزارش خطای ساختار.
* `tests/severity-scorer.test.ts`: ارزیابی صحت تفکیک لایه‌های فیلترینگ و محاسبه سطوح ۰ تا ۵.
* `tests/security.test.ts`: آزمون عدم نشت پسوردها، رمزنگاری AES-256-GCM و ماسک‌کردن آدرس‌های IP در لاگ.
* `tests/singbox-config.test.ts`: بررسی تولید ساختار استاندارد sing-box با Inbound مخلوط، حالت TUN و استثنای دامنه‌های ir.
* `tests/database.test.ts`: آزمون تراکنش‌های دیتابیس SQLite محلی، مهاجرت ساختار جداول و ثبت تاریخچه.

## ۶. فهرست محدودیت‌های فنی و واقعیت‌های شبکه ایران
1. **قطع کامل فیزیکی فیبر نوری بین‌الملل:** چنانچه دروازه‌های ارتباطی TIC با جهان خارج مسدود شده و ترافیک بین‌الملل به صفر برسد، هیچ نرم‌افزاری بدون سخت‌افزار مستقل ماهواره‌ای قادر به خلق اینترنت نیست. برنامه در این حالت وضعیت «سطح ۵ - اینترنت ملی» را با شفافیت اعلام می‌کند.
2. **مجوز Administrator برای حالت TUN:** اجرای کارت شبکه مجازی Wintun در سطح کرنل ویندوز نیازمند دسترسی ادمین است؛ حالت پیش‌فرض (System Proxy) بدون نیاز به این مجوز کار می‌کند.
3. **محدودیت سرعت پل‌های داوطلبانه Snowflake:** پل‌های رایگان برای ارتباط متنی، پیام‌رسان‌ها و وب‌گردی اضطراری پایدار هستند، اما به دلیل ماهیت داوطلبانه گره‌ها سرعت آن‌ها برای دانلود سنگین محدود است.
